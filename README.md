# Woman of the Bible – Study & Journal App

A faith-based Bible study and journaling web app designed for women to reflect, study scripture, and document personal insights in a calm and private digital space.

## Features
- Guided Bible study lessons
- Reflection questions
- Personal journaling using local storage
- Prayer and devotion sections
- Minimal, peaceful UI design

## Tech Stack
- HTML
- CSS
- JavaScript
- Local Storage

##  Purpose
Built to merge faith and technology while creating a meaningful product that serves real users and communities.
